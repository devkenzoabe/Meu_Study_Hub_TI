# IA Agêntica (Agentic AI) - Curso NVIDIA

## Tópicos abordados

- O que é um agent (agente) e o loop Percebe → Raciocina → Atua → Aprende
- IA Agêntica (Agentic AI) vs. IA Generativa (Generative AI)
- Principais características de um agent
- Arquitetura agêntica: camadas de percepção, decisão, ação e aprendizado
- Princípios de engenharia: decomposição agêntica, engenharia de contexto (context engineering), design de workflow (fluxo de trabalho) e seleção de modelo
- Padrões de design agênticos: Reflection, Tool Use, Hierarchical e Reactive
- Papéis em sistemas multiagentes: Planner, Executor, Critic, Tool-User e Coordinator
- Aplicações no mundo real: telecomunicações, data flywheel, experiência do cliente e governança
- Como construir e escalar: o ReAct loop (Reason and Act, raciocinar e agir)
- Frameworks: LangChain, LangGraph, Crew.ai e NVIDIA NeMo Agent Toolkit
- Tendências atuais e desafios éticos

## Ideia-chave do curso

> Generative AI cria conteúdo; Agentic AI faz as coisas acontecerem.

## Por que estudei isso

Meu objetivo é me tornar Engenheiro de Inteligência Artificial, e os agents estão entre as áreas que mais crescem na IA. Este resumo registra a base conceitual que quero usar para construir meus primeiros agents.
