## O que tem em cada pasta

| Pasta | Conteúdo |
|-------|----------|
| [`01_Apresentacao_e_Perfil`](01_Apresentacao_e_Perfil/) | Quem sou eu, meus objetivos e onde me encontrar |
| [`02_Disciplinas_Atuais`](02_Disciplinas_Atuais/) | Atividades, entregas e resumos de cada disciplina do 1º semestre |
| [`03_Projetos_e_Certificados`](03_Projetos_e_Certificados/) | Projetos pessoais, certificados e cursos complementares |

### Projetos em destaque

- 🎮 [Jogo do Número Secreto](03_Projetos_e_Certificados/Jogo_do_Numero_Secreto/): jogo de adivinhação feito com HTML, CSS e JavaScript
- 🤖 [IA Agêntica - Curso NVIDIA](03_Projetos_e_Certificados/NVIDIA_Agentic_AI/): resumo do curso Agentic AI Explained, do NVIDIA Deep Learning Institute

## Padrão das disciplinas

Cada disciplina segue a mesma organização:

- `Atividades_e_Entregas/`: trabalhos e exercícios entregues
- `Anotacoes_e_Resumos/`: resumos e anotações de estudo
