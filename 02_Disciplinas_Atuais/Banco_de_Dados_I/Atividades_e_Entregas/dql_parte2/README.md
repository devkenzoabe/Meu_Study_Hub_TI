# Atividade DQL - Parte 2 (Análise de Clientes Bancários)

## Sobre a atividade

Esta pasta contém a resolução da segunda lista de exercícios de **DQL (Data Query Language)** da disciplina de **Banco de Dados I**. As consultas foram desenvolvidas para extrair indicadores, métricas financeiras e análises de perfil a partir da tabela `clientes_banco`, que registra o histórico mensal de clientes ao longo de 2024.

## Conteúdos praticados

* Consultas de seleção e filtragem com `SELECT` e `WHERE`
* Operadores de comparação, intervalos de datas (`BETWEEN`) e condições compostas (`AND`)
* Contagem de registros únicos com `COUNT(DISTINCT ...)`
* Funções de agregação (`COUNT`, `SUM`, `AVG`, `MAX`) e arredondamento (`ROUND`)
* Agrupamento de dados com `GROUP BY` e filtragem de grupos com `HAVING`
* Ordenação e limitação de resultados com `ORDER BY` e `LIMIT`
