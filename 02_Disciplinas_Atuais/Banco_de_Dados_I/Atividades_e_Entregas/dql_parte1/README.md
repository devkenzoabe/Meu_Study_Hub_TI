# DQL — Parte 1

## Sobre a atividade

Atividade prática da disciplina **Banco de Dados I**, com exercícios de SQL utilizando o banco de dados `mercado`.

O objetivo é praticar consultas e manipulação de dados por meio de comandos DQL (*Data Query Language*).

## Conteúdos praticados

- `SELECT` — seleção de dados.
- `WHERE` — filtragem de registros.
- `ORDER BY` — ordenação de resultados.
- `LIMIT` — limitação de resultados.
- `DISTINCT` — remoção de duplicatas.
- `COUNT()`, `SUM()`, `AVG()`, `MIN()` e `MAX()` — funções de agregação.
- `GROUP BY` e `HAVING` — agrupamento e filtragem de grupos.
- `LIKE`, `BETWEEN`, `IS NULL` e `IS NOT NULL`.
- Operações matemáticas e cálculos percentuais.
